How do I get a token? (one-time, 2 minutes)
  1. On GitHub, open Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Token name: FA Vision Admin. Expiration: 1 year.
  3. Repository access: Only select repositories → favisionenterprize.github.io.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it and paste it above.

The token stays in this browser only. Anyone with it can change your website, so don't share it. If a phone is lost, delete the token on GitHub and make a new one.

  • Photos sell furniture. Shoot in daylight, landscape, against a plain wall.

    • 
          
  • Honest price. Real prices get more serious buyers than "call for price".
