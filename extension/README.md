# FA Vision Price Sync (browser add-on)

Lets the admin's **Price sync → Sync** buttons update Facebook Marketplace listing prices by themselves.

Install once in Edge or Chrome: open `edge://extensions` (or `chrome://extensions`), turn on **Developer mode**, click **Load unpacked** and choose this folder. Reload the admin; Price sync then shows "FA Vision sync add-on is installed".

It only runs on `facebook.com/marketplace/…` pages opened by the admin with a sync queue, and on the admin itself (to say it's installed). It types the price, taps **Update**, moves to the next listing, then returns to the admin, which marks them synced.
